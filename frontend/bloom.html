How the runs differ

Strict run_01 requires a common patch ≥3 pixels above training P90 on three consecutive observed days: 23 training components, no positive validation/test targets. Relaxed run_02 uses P75 and a patch ≥2 pixels on one observed day: the first passing definition from a bounded training/2024-validation label comparison. It does not establish multi-day persistence. Gap-tolerant candidates were checked but not selected; missing days never become event labels. Any probability calibration is a 2024 development fit, not operational approval.
